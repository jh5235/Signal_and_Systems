# 실험 설계 및 결과 — Optuna 기반 DSP 잡음 제거 파라미터 튜닝

## 1. 목적

재우의 1회차 제출물은 Log-MMSE 스펙트럼 진폭 추정 + 고정/추적 결합 잡음 PSD 추정 + 저주파 가중으로 구성된 전통적 DSP 알고리즘이며, 파라미터는 직접 짠 coordinate descent(`experiments/tune.py`, `tune2.py`)로 정했습니다(Optuna 코드는 없음). 이 실험은 **같은 알고리즘·같은 목적함수에서 탐색 방법만 Optuna(TPE)로 바꿨을 때** PESQ가 더 오르는지 확인합니다. 알고리즘 구조는 바꾸지 않습니다.

## 2. 설계

| 항목 | 내용 |
|---|---|
| 데이터 | `noise_reduction_challenge` train 1296개 / validation 164개 (16 kHz, 3초) |
| 목적함수 | train 무작위 400개(`RandomState(1)`, 원본 coordinate descent와 동일 subset)의 평균 PESQ-WB, 최대화 |
| 최종 확인 | validation 164개 PESQ-WB, SNR (탐색에 사용하지 않음) |
| 탐색기 | Optuna 5.0 `TPESampler(multivariate=True, n_startup_trials=30, seed=0)` |
| trials | 299 (SQLite `optuna.db`에 저장, 재개 가능) |
| 시작점 | 원본 `pesq` 프로파일을 첫 trial로 enqueue (warm start) |
| 소요 시간 | 약 1,880초(31분), trial당 약 6.3초, 14 프로세스 |

### 탐색 공간 (13개)

| 파라미터 | 범위 | 의미 |
|---|---|---|
| `n_fft` | {768, 1024, 1536, 2048} | STFT 길이 |
| `hop` | {128, 192, 256} | STFT hop |
| `frac` | 0.03 – 0.3 | 고정 잡음 추정에 쓰는 최저 에너지 프레임 비율 |
| `w` | 0 – 1 | 고정/추적 잡음 추정의 기하평균 가중 |
| `a_pow` | 0.8 – 0.98 | SPP 추적기 평활 계수 |
| `xi_h1_db` | 5 – 25 | SPP 추적기의 음성 존재 시 사전 SNR |
| `noise_scale` | 0.8 – 2.5 | 잡음 과대 추정 계수 |
| `a` | 0.85 – 0.99 | decision-directed 평활 계수 |
| `xi_min_db` | −35 – −5 | 사전 SNR 하한 |
| `gmin_db` | −45 – −8 | 이득 하한 |
| `hp_hz` | 60 – 400 | 저주파 가중 기준 주파수 |
| `hp_order` | 2 – 6 | 저주파 가중 차수 |
| `hp_floor_db` | −40 – −5 | 저주파 가중 최대 감쇠 |

원본 coordinate descent는 파라미터마다 5~6개 후보값만 훑었고 한 번에 하나만 바꿨습니다. 이번에는 연속 범위를 쓰고 파라미터 간 상호작용을 함께 탐색합니다.

전체 값은 `02_result/best_params.json`입니다. 가장 큰 변화는 저주파 가중입니다. 기준 주파수를 240 Hz에서 384 Hz로, 차수를 4에서 6으로 올려 더 높고 가파르게 저역을 자릅니다.

### 3.2 성능

| 지표 | 원본 `pesq` | Optuna | 변화 |
|---|---:|---:|---:|
| Train subset PESQ (목적함수) | 1.9842 | 2.1006 | +0.1164 |
| **Validation PESQ-WB** | 2.0037 | **2.0505** | **+0.0468** |
| Validation SNR (dB) | 5.64 | 2.94 | −2.70 |

(Noisy 입력: PESQ 1.3947, SNR 9.63 dB)

타깃 SNR별 validation (Optuna):

| 타깃 SNR | Noisy PESQ | Optuna PESQ | 원본 PESQ (README) |
|---|---:|---:|---:|
| 0 dB | 1.080 | 1.401 | 1.358 |
| 5 dB | 1.218 | 1.735 | 1.742 |
| 10 dB | 1.358 | 2.050 | 2.011 |
| 15 dB | 1.635 | 2.440 | 2.347 |

잡음 종류별 결과는 `02_result/validation_optuna_scores.csv`에 있습니다. 개선 폭이 큰 쪽은 phone_dialing(2.09→3.91), vehicle_interior(1.86→3.19), military_vehicle(1.42→2.62)입니다. bell(1.675→1.674), animal(1.42→1.54), clap(1.38→1.45)은 거의 변화가 없는데, 이런 충격성·비정상 잡음은 이 구조로는 줄이기 어렵습니다.

### 3.3 외부 데이터 검증 (`04_test/`)

VoiceBank-DEMAND(Hugging Face `JacobLinCool/VoiceBank-DEMAND-16k`, test 824개)로 평가했습니다. 튜닝에 쓰지 않은 화자·잡음·SNR입니다.

| 입력 / 프로파일 | PESQ-WB | SNR (dB) |
|---|---:|---:|
| Noisy 입력 | 1.9707 | 8.45 |
| 원본 `pesq` | 2.6468 | 8.49 |
| Optuna | 2.7887 | 4.87 |
| `balanced` | 2.4576 | 15.22 |

Optuna는 원본보다 +0.142(bootstrap 95% CI 0.135~0.149, 파일의 93.6%에서 우위)로, 챌린지 데이터가 아닌 곳에서도 개선이 유지됩니다.

## 4. 해석과 한계

- **과적합 격차**: train에서는 +0.116 올랐지만 validation에서는 +0.047로 절반 이하입니다. 400개 subset에 어느 정도 맞춰졌다는 뜻이며, 그래도 validation에서 개선이 유지됐습니다. 5 dB 구간은 원본보다 약간 낮습니다(1.735 vs 1.742).
- **수렴**: 약 240 trial 이후 best가 2.1004~2.1006에서 정체했습니다. 상위 trial들이 서로 비슷한 값이어서 이 알고리즘 구조에서의 PESQ 한계에 가깝습니다.
- **PESQ–SNR trade-off 심화**: PESQ만 목적함수여서 저역을 더 강하게 잘랐고 SNR이 5.64 → 2.94 dB로 내려가 noisy 입력(9.63 dB)보다 6.7 dB 낮습니다. SNR이 평가 항목이면 SNR 제약이나 가중합 목적함수(다목적 Optuna)로 다시 탐색해야 합니다.
- **외부 일반화**: VoiceBank-DEMAND에서도 원본보다 +0.142 높아 개선이 데이터셋 특성에만 의존하지는 않습니다. 다만 이 데이터는 잡음이 정상적이고 SNR이 높아 저주파 억제가 유리했을 수 있습니다.
- **한계**: seed 1개, subset 1개로 한 번만 돌렸습니다. 개선폭(+0.047)이 seed·subset 변동보다 큰지는 반복 실행으로 확인하지 않았습니다.
